# Kaban — презентация на утверждение

Файл: `kaban-presentation.html`: один файл, CSS/JS и макеты внутри (base64), без внешних ресурсов (~10.8 МБ).

- Навигация: ← → / пробел / PageUp/PageDown / Home/End, кнопки внизу, счётчик слайдов.
- PDF: Печать → «Сохранить как PDF», поля «Нет», включить «Фон». Один слайд — одна страница (16:9).
- Пересборка: `python3 build.py`. Каждый запуск заново читает PNG из `../design/png/` и встраивает их (нужен Pillow, чтобы разрезать `02-cards.png` на два слайда). Если PNG пропал, на его месте появится заглушка «Дизайн: макет будет добавлен».
- Исходники: `src/slides-a.html` (1–9), `src/slides-b.html` (10–18), `src/design-intro.html` (19), слайды дизайна (20–27) генерирует `build.py`, `src/slides-c.html` (28–31).

Источники: architecture-v0.md v0.9, kaban-mvp-features-usecases.md v0.6, frontend-plan-v0.md v0.4.1, backend-plan-v0.md, kanban-factory-research.md, design/README.md + design/png (макеты v0.1).
