# Архив Kaban

Материалы сохраняют историю разработки и не устанавливают действующие правила.
Текущий вход — [current-state](../current-state.md), политика — [contributing](../contributing.md).

В `2026-10-04/` сохранены полные версии старых contributing/getting-started,
frontend/backend планов и merge-order, а также журналы изменений архитектуры
и спецификации. Старые абсолютные пути, версии Drive, очереди PR и ограничения
ролей описывают ту сессию. Относительные ссылки внутри полных снимков сохраняют
исходную структуру и могут требовать поиска файла по имени.

Frontend-требования экранов, приёмка и fixtures разнесены по `docs/frontend/`;
runtime описывает актуальный код, а исходный документ доступен
для сравнения. История и закрытые обсуждения не удалены и не должны загружаться
целиком перед обычной задачей. Материалы `docs/team2/` также являются историческими.

В `drive-2026-10-05/` сохранены оригинальные версии Drive, для которых в Git уже
были более новые требования, полная исходная спецификация с журналом,
[презентация](drive-2026-10-05/presentation/kaban-presentation.html) и
[отменённый чек-лист второй команды](drive-2026-10-05/second-team-checklist-v2.txt).
Пути и контрольные суммы — [реестр импорта](../drive-import-2026-10-05.json).
