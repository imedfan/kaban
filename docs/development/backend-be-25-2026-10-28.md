# BE-25: production stream, model init и лимиты

Дата: 28 октября 2026. Ветка `codex/be-25-cursor-stream`.
Зависимость — открытый draft [PR #129](https://github.com/imedfan/kaban/pull/129)
(BE-24), HEAD `1bbc2b7`. После `git fetch origin` main — `ad0ed88`.
Изменения BE-24 не переписаны; эта ветка включает их как зависимость.

## Поведение

- Production ingestion первого `system/init` сверяет actual display name с
  каталогом для `RunSummary.requestedModel`, зафиксированного при старте. Смена
  task override во время run не меняет сравнение, пул ошибки или адресата флага.
- Log cursor, первый init, actual name/session, journal, состояние и kill outbox
  записываются атомарно. Physical kill исполняется после commit и до exit
  classification. Outbox переживает потерю ответа/перезапуск; результат позднего
  MCP completion после mismatch не принимается.
- Перед MCP tool call читается уже доступный process stream, чтобы быстрый
  `complete_stage` не был принят раньше периодического observer.
- Неизвестное/неоднозначное имя даёт `model_unconfirmed` и продолжение.
  Повторные init, в том числе после reopen, не меняют первый результат.
  `taskUpdated` обновляет открытые details через обычный journal.
- Additive migration v25 хранит init/tool/error facts отдельно от retention
  нормализованного лога; первые события не ищутся в обрезаемом префиксе.
- Парсер выбирает единственный `*ToolCall` payload среди metadata siblings,
  проверяет nested `result.success.exitCode/isError` и error/failure.
  Thinking из наблюдаемого print-потока не считается неизвестной ошибкой и
  не публикуется. CamelCase usage, CRLF/chunks, последняя строка без LF и
  нечисловые/overflow поля разбираются без выдуманного нуля и падения.
- Реальный `Available models` listing дополняет legacy TSV. Неизвестные строки
  не заменяют каталог. Actual name теперь можно подтвердить реальными данными.
- Классификация использует error envelopes и plain CLI diagnostics, а не текст
  user/assistant/tool output. Ошибки после длинного stdout сохраняются при ingestion.
  Init/user/thinking без вызовов tools и изменений файлов не расходуют попытку:
  `retry_wait(silent_exit)` и существующая очередь проб BE-30, включая ненулевой exit code.
  Обычный crash после tools/изменений файлов сохраняет прежние списания и rollback.

## Фикстуры и доказательства

Реальные потоки CLI `2026.09.23-86fc751` скопированы без изменения из
[BE-22](../../research/spike-1-2026-10-28/RESULTS.md) в
`Tests/KabanKitTests/Fixtures/BE22/`. Run-1 даёт шесть started/completed tools,

без tools. Реальный каталог подтверждает `cursor-grok-4.6-medium` / `Grok 4.6 Medium`.
Logged-out JSON — реальная environment probe, а не stream error.

Rate-limit, usage/spendLimitHit, resource_exhausted, stream auth, silent exit,
ошибки инструментов и подмена модели — **синтетические** тестовые данные.
В budget BE-22 живые лимиты и подмена/fallback не получены. Новые платные
запуски, installed helper и системная регистрация в этой задаче не выполнялись.

Production-adapter тесты используют настроенный synthetic Cursor, отдельный
run HOME, frozen RunSpec и настоящий process group. Проверяются stop/refund,
first-init/reopen, смена override, поздний completion, гонка MCP до periodic poll,
rollback marker/journal/outbox при DB failure и все лимитные переходы/флаги.

## Граница UC-22

BE-22 run-2 подтвердил один kill по init: SIGTERM/returncode -15,
ни одного tool_call и MCP tools/call. Это закрывает экспериментальную проверку
BE-14, но не доказывает универсальной гарантии остановки CLI до первого инструмента.

Production observer читает файлы. Между записью init и чтением CLI может уже
запустить shell или изменить файл. Синтетический stop test содержит паузу до
инструмента и подтверждает реакцию после наблюдения. Проверка перед MCP закрывает
приём результата при уже доступном init, но не является барьером для shell или
невыведенного/buffered init. Гарантированно чистый клон при mismatch не доказан.
Для строгого контракта нужен подтверждённый CLI execution gate перед tools или
контроль каждого внешнего эффекта. Требование не ослаблено; полный UC-22/MVP открыт.
