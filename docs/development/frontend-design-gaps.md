# Frontend MVP: недостающие материалы дизайнера

Обновлено 7 октября 2026. Рабочий список по поручению Артёма; дополняется
при выполнении [FE-01–22](frontend-mvp-tasks.md). Отсутствие макета не отменяет
требование: пока используем утверждённые токены и нативные элементы управления.
Оригинальные файлы `design/` не перерисовываются.

| Задача / состояние | Пробел в источниках | Принятое решение / что нужно от дизайнера |
| --- | --- | --- |
| FE-01: служба ещё не подключена, разрешение macOS, ошибка протокола | В [реестре](../../design/README.md) нет кадров службы/подключения; исходники base/v0.2/v0.2.1 не задают композицию этих состояний | Нативная панель шириной до 560 pt, wordmark, объяснение, отдельный статус/ошибка и две кнопки стандартного размера. Нужны light/dark кадры loading/approval/error с длинным текстом и минимальным окном. Реализация проверяется в настоящем WindowGroup. |
| FE-02: reconnect/catch-up, неизвестная отправка и сохранённый draft | В [реестре](../../design/README.md) нет кадров recovery/pending: не заданы баннер, длинная ошибка и форма с неизвестным исходом | Используем control/card tokens и компактный баннер; форма имеет прокрутку с отдельным footer, Close доступен при pending. [Проверенные кадры](frontend-fe-02-2026-10-06.md#визуальная-проверка-настоящего-окна). Нужны light/dark кадры этих состояний при 1040×640 pt, с длинным сообщением и сохранённым вводом. |
| FE-03: первый запуск, Cursor/auth/toolchain и необязательные разрешения | В [реестре](../../design/README.md) нет кадров онбординга, выбора CLI и последовательности helper → environment → permissions | Нативный экран с тремя секциями, content width до 760 pt, прокруткой и постоянным footer; используем прежние card/control/status tokens. [Проверенные состояния](frontend-fe-03-2026-10-07.md#визуальная-проверка-настоящего-окна). Нужны light/dark кадры approval/denied, missing/not-runnable/not-logged-in, git/sandbox error, pending path и пропуска уведомлений, включая длинный path и 1040×640 pt. |
| FE-04: pending, non-git, relink/remove и подключённый проект | Макет `06-add-project-identity` задаёт автора; в реестре нет композиции остальных project lifecycle состояний | Сохраняем форму шириной 600 pt, прежние tokens, scroll body и постоянный footer. [Проверенные состояния](frontend-fe-04-2026-10-07.md#визуальная-проверка-настоящего-окна). Нужны light/dark кадры non-git/duplicate/access lost/pending, relink/remove и success с branch/gates, no_pipeline/invalid, длинным path в 1040×640 pt. |
| FE-05: compact/hidden/gate и плотная доска | Основная композиция и mascot kit есть; в реестре 28 кадров нет отдельных compact, hidden stage, WIP overflow и minimum frames | Сохраняем native дорожки и tokens. [12 проверенных состояний](frontend-fe-05-2026-10-07.md#визуальная-проверка-настоящего-окна). Нужны light/dark minimum композиции compact с StageChip, gate раскрыт/свёрнут, hidden, overflow, +N badges, вставки дорожки и picker pending/error. |
| Создание задачи / пустая доска (FE-04/06) | [design/README](../../design/README.md) прямо фиксирует отсутствие оригинальных кадров | Используем имеющиеся токены и native controls; окончательная оценка и размеры — в соответствующей FE-задаче. Нужны кадры пустой доски, пустого проекта и формы с ошибкой/pending. |
| Часть настроек suspicious files (FE-18) | В [реестре](../../design/README.md) отмечена отложенная часть настроек | До FE-18 определить точные недостающие состояния по требованиям. Нужны формы шаблонов/исключений и их ошибки, не изменение существующего suspicious-card дизайна. |
| FE-06: create/edit/priority, stale/unknown body и empty search | В реестре отсутствуют оригинальные кадры создания, редактора, первоначального приоритета и сравнения изменившегося текста. Нет light/dark размеров pending/refusal при минимальном окне. | Использован native sheet 560 pt, единый Markdown editor/preview, постоянные footer и действия сверки, отдельная форма числового приоритета. [11 проверенных кадров](frontend-fe-06-2026-10-07.md). Нужны кадры обычного/длинного/неизвестного описания, stale comparison, pending/error, создания с приоритетом и empty search при 1040×640 pt. |
