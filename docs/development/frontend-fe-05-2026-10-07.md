## Реализованная поверхность

Основное WindowGroup использует прежние BoardStore/BoardSession/KabanClient.
Дорожки сохраняют display.order; скрытые стадии доступны отдельным фильтром,
display.collapsed и gate strip раскрываются из заголовка. У дорожки собственная
горизонтальная прокрутка, у колонок ограниченная высота и LazyVStack.
LaneHeader закрепляется при вертикальной прокрутке. Одиночная колонка не
растягивает карточку на всю ширину окна.

Компактный вид группирует по смыслу: очередь / работа агентов / ждут человека /
слияние / завершены. Любая waitingHuman, включая review в agent-стадии,
попадает в ожидание. StageChip сохраняет проект и исходную стадию.
Совпадение stageId у различных pipeline не определяет общую колонку.

Проекты перетаскиваются из сайдбара и ручки дорожки; подсвечивается место вставки.
Существуют context menu show/hide/reorder, Cmd-1…9 и Cmd-Option стрелки
вверх/вниз и влево/вправо. BoardSet остаётся локальным; подписка охватывает
скрытые проекты. Waiting и incident badges используют полную проекцию.

WIP берётся только из StageLoad. Превышение вроде 4/2 выделяется янтарным,
карточки сохраняются. При nil load WIP скрыт; подпись «Задач» в свёрнутой
стадии обозначает число карточек, не загрузку WIP. В компактном виде WIP нет.

Карточка показывает двухстрочный заголовок, все TaskState/reasons, критерии,
попытки, counters возвратов, overlaps и модель. Не более двух бейджей, остальные
доступны через +N/help; порядок — git grants, возвраты, overlaps, модель/прочее.
Неоднозначный legacy bounce key остаётся исходным ключом, без угаданной пары.

Running подписан «Запуск зарезервирован». RunSummary.startedAt/updatedAt
не превращаются в таймер живого процесса. Число резервирований отдельно;
подтверждённые процессы неизвестны, gating и waitingHuman в него не входят.
Progress показывается только по task/run/stage и незавершённому текущему
RunSummary из getTaskDetail; чтение защищено полной карточкой, generation и
отменой. Старый report другого run или после перехода не появляется.
Подмена модели использует actualModelName из read DTO, если он доступен.

Retry countdown возможен только по retryAt и chargesAttempt. Несписывающие
rateLimit/runnerAuth/daemonRestart/silentExit не получают личного таймера.
TimelineView существует только у видимой карточки. В Reduce Motion вместо
таймера отображается абсолютное время; маскоты статичны. Исходный mascot kit,
восемь фактур и native picker используют setMascot / correlated projectUpdated.
Маскот в карточке остаётся статичным, а sidebar/header анимируется по смене состояния и journal-переходу в Done.

## Незавершённая приёмка

Первые три критерия FE-05 подтверждены. Последний остаётся открытым:
light/dark/minimum/empty/long и opt-in Reduce Motion path проверены,
но ручной pointer drag/autoscroll, системное переключение Reduce Motion,
VoiceOver и compositor не проверены. Native smoke вызывает общий drop handler,
а не синтезирует настоящий pointer gesture. Полная задача не объявлена принятой.

Текущий wire не сообщает подтверждённые процессы/actual process start,
wall deadline, queue position, структурированную причину общего bounce limit
и gate step progress. Их нет в UI, а требования сохранены. Уточнение
conflict limit выводится лишь из известного onConflict и merge_conflict;
неизвестный общий limit не вычисляется суммированием.
Production Cursor/installed helper проверка остаётся отдельной зависимостью.
Конкретные [технические пробелы](frontend-backend-integration-gaps.md) и
[недостающие designer frames](frontend-design-gaps.md) ведутся отдельно.
