## Поведение

После authoritative применения `addProject` лист показывает команды и имена
стадий из `PipelineSummary.stages[].gates`: например, «Гейты: swift build,
swift test — в Dev и Merge». Подтверждения или выбора гейтов нет; клиент
оставляет `addProject.gates` отсутствующим, как требует автоматическое
определение BE-33. Пустой набор сообщает об отсутствии гейтов и редакторе
пайплайна; отсутствующий/неразобранный пайплайн остаётся неизвестным.
Наличие ошибок выбора модели не скрывает сохранённые команды.

Повторный `detectGates` из диагностики формы удалён: найденные сейчас команды
не доказывают, что они сохранены. Это особенно важно для существующего
пайплайна с собственными командами. `pipelineApplied` обновляет сообщение;
`.ok` до события не показывает успешный результат. Изменение и удаление
гейтов остаются в существующем `PipelineEditorStore`.

Native-проверка выявила дефект редактирования пустой модели с комментарием
в шаблоне: значение склеивалось с `# required`, делая YAML невалидным.
`PipelineTextDocument` теперь сохраняет разделитель перед комментарием;
добавлена регрессия для LF/CRLF. Валидатор демона не менялся.

## Повторение

```sh
KABAN_SCENARIOS=Scenarios/M1 swift test
KABAN_SCENARIOS=Scenarios/M1 swift test --filter 'ProjectLifecycleStoreTests|PipelineEditorTests|ProjectLifecycleTests'
xcodebuild -project Kaban.xcodeproj -scheme Kaban \
  -destination 'generic/platform=macOS' -derivedDataPath /tmp/kaban-fe26-app \
  ONLY_ACTIVE_ARCH=YES CODE_SIGNING_ALLOWED=NO build
python3 tools/check-project-context.py
```

Для native smoke создать новый каталог `/tmp/kaban-fe26-<suffix>/repository`,
инициализировать git с веткой `main`, автором и первым коммитом. Для `found`
закоммитить `Package.swift`; для `empty` build descriptors не добавлять.
Для `existing` заранее закоммитить стандартный шаблон с командой
`custom verify --strict` у Dev и Merge. Для `long` — та же схема с командой
`verify ` + 14 повторов `very-long-command-argument/` + ` --strict`.

```sh
/tmp/kaban-fe26-app/Build/Products/Debug/Kaban.app/Contents/MacOS/Kaban \
  --developer --developer-database /tmp/kaban-fe26-<suffix>/state.sqlite \
  --project-smoke /tmp/kaban-fe26-<suffix>/result.json \
  --project-smoke-gates YES --qa-gate-mode found \
  --project-smoke-repository /tmp/kaban-fe26-<suffix>/repository \
  --qa-theme light --qa-size minimum \
  --export-live-window /tmp/kaban-fe26-<suffix>/window.png
```

Smoke меняет только private repo/БД; каждый повтор требует новой пары.
`*.result.png` — результат листа, `*.configured.png` — исходные гейты Merge,
основной PNG — редактор после применения.
