# FE-34: демо-код вне поставки

9 октября 2026. Проверенная после fetch база main `ec20437`.
Ветка `codex/fe-34-release-ui`, реализация `bf6ef6d`.

## Изменение

Исходный Release содержал ReferenceDemo, NativeShell, ReferenceSettings,
AppFixture и QA-клиенты. Неиспользуемые демо-экраны удалены из исходников и
Xcode target. Тема, chip, mascot, backdrop и wordmark перенесены в общие
Kaban-компоненты. Их тела сверены с исходником базы после замены имён и
переноса чтения QA-аргументов. Цвета, размеры, анимация и композиция сохранены.
Визуальные источники остаются в design/ по принятому приоритету версий.

AppFixture, BoardQA, QA-клиенты и NativeWindowCapture компилируются только с
KABAN_QA. Debug задаёт флаг, обычный Release не задаёт. AppArguments сохраняет
чтение developer-параметров в обеих сборках и отключает QA-параметры в Release.
Основной runtime использует существующий DaemonRuntime и реальный клиент.
Protocol, BoardCore, backend, entitlements и регистрация службы не менялись.

## Проверки

| Критерий | Доказательство | Результат |
|---|---|---|
| Release не содержит демо и неиспользуемых экранов | check-app-build-contents.py читает реальные Mach-O symbols | пройден, demoTypes=[] и qaTypes=[] |
| Общие компоненты остаются в приложении | символы пяти Kaban-компонентов в Release и Debug; сравнение исходных тел | пройден |
| QA включается отдельным compile condition | Debug build, AppFixture/BoardQA/native capture в Debug dylib; отсутствие в Release | пройден |
| BoardQA продолжает работать | 9 fixture native smoke и 8 pipeline native сценариев через production daemon/private stdio | пройден, strict keyboard/control тоже прошёл отдельным повтором |
| Основное окно сохраняет оформление | actual WindowGroup light/dark minimum, long и empty | четыре финальных кадра просмотрены |

Regression checker сначала упал на исходном Release:
`Demo types found in application: NativeAddProjectForm, NativeReturnForm, NativeSettingsView, NativeShell, … ReferenceDemo … ReferenceFrameView …`.
После изменения Debug и Release builds прошли, обе проверки содержимого прошли.
На SDK 27 пустой CommandsBuilder потребовал macOS 27. Явный EmptyCommands,
доступный с macOS 11, сохраняет deployment target macOS 26.
Checker учитывает Kaban.debug.dylib, поскольку Debug executable в новом Xcode
содержит только загрузчик. Проверки обеих конфигураций добавлены в macOS CI.

Fixture checks: ui-light, ui-dark, control-routing, strict control, details, log,
answer, review, merge. UI smoke проверяет настоящее окно, typed events и keyboard/menu flow.
Первый прямой запуск UI не получил keyboard focus; запуск через LaunchServices,
как в CI, прошёл в обеих темах. Отдельный strict control smoke потерял focus
и не открыл лист, active=false/key=false. Control-routing прошёл. Отдельный
повтор strict control через LaunchServices прошёл на той же сборке без изменения
assertions: pause/resume, retry, move, Escape и cancel через native меню и листы.
Первый отказ и успешный повтор сохранены в checks. Результат CI относится к его HEAD.

Production daemon/private stdio driver прошёл apply-light, reopen-dark-minimum,
forms-light-minimum, executor-dark, yaml-dark-minimum, invalid-light-minimum,
long-dark-minimum и absent-light-minimum. Проверка использовала новый synthetic
репозиторий `/tmp/kaban-fe13-jxrh188_`, без Cursor и установленного helper.
Fixture smoke и четыре кадра сохранены локально в `/tmp/kaban-fe34-native`.
[Checks и SHA-256 кадров](frontend-fe-34-2026-10-09-checks.json) связывают их с
реализацией. PNG и снимки рабочего стола пользователя в PR не включены.

Среда: Apple Silicon, Swift 6.4, Xcode 27.0 (27A266a), macOS 27.0.1 (26A434).
Обе сборки unsigned, CODE_SIGNING_ALLOWED=NO. Новый VoiceOver и отдельная
проверка системных accessibility settings не выполнялись. SwiftPM tests локально
не повторялись: Sources и Tests не менялись; полный прогон остаётся в CI.
Установка helper, автозапуск и полный FE-22 сценарий этим отчётом не закрываются.

## Воспроизведение

```sh
xcodebuild -project Kaban.xcodeproj -scheme Kaban -configuration Release \
  -destination 'generic/platform=macOS' -derivedDataPath /tmp/kaban-release \
  ONLY_ACTIVE_ARCH=YES CODE_SIGNING_ALLOWED=NO build
python3 tools/check-app-build-contents.py \
  --app /tmp/kaban-release/Build/Products/Release/Kaban.app
xcodebuild -project Kaban.xcodeproj -scheme Kaban -configuration Debug \
  -destination 'generic/platform=macOS' -derivedDataPath /tmp/kaban-qa \
  ONLY_ACTIVE_ARCH=YES CODE_SIGNING_ALLOWED=NO build
python3 tools/check-app-build-contents.py \
  --app /tmp/kaban-qa/Build/Products/Debug/Kaban.app --qa
python3 tools/check-pipeline-editor.py \
  --app /tmp/kaban-qa/Build/Products/Debug/Kaban.app
python3 tools/check-project-context.py
```
Fixture команды и проверка strict keyboard flow сохранены в CI.
