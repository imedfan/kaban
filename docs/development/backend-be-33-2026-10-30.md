# BE-33: автоматические гейты шаблона

База: origin/main `5adc972`, обновлена через fetch 30.10.2026.
Ветка: `codex/be-33-auto-gates`.

При addProject с новым шаблоном демон использует существующий detector build
descriptors из выбранной закоммиченной базы. Найденные команды записывает
в dev и merge до подготовки Git tree/commit. test и ai-review гейтов не получают.
Нет найденных команд — исходный шаблон без gates. Существующий pipeline
не меняется; шаблон по-прежнему требует явного выбора моделей.

DTO addProject получил optional gates: отсутствие включает detector,
пустой массив явно отключает гейты. Это сохраняет legacy requests и позволяет
клиентам передавать результат определения. Непустые gates без createTemplate
дают invalid до создания проекта или Git objects шаблона. Команды сериализуются
как JSON-массив строк (валидный YAML), чтобы кавычки и двоеточия оставались
частью команды.

Durable intent хранит подготовленные blobs и commit; recovery не определяет
гейты заново и не создаёт второй коммит. Тест публичной команды проверяет
выбранную базу develop, Swift build/test только на dev/merge, четыре файла
только внутри .kaban/, один коммит и повтор после reopening. Дополнительно
проверяются отсутствие гейтов, явные команды, wire request/refusal fixtures
и отказ без побочных эффектов. StageGateTests проверяет complete_stage и
красный гейт, остающийся на той же dev-стадии.
