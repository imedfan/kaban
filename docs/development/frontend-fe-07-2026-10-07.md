## Реализованная поверхность

Карточка, детали и меню «Задача» открывают один native sheet для pause/resume,
move, cancel и retry. Команды отправляет прежний BoardSession/KabanClient.
Диалог связан с полной исходной карточкой, pipeline и generation сессии;
изменение источника блокирует отправку и предлагает открыть действие снова.
Команда повторно проверяется непосредственно перед send. Успешный ответ сам
не перемещает карточку и не снимает pending: нужен correlated event или
исходный receipt, покрытый применённым authoritative snapshot по контракту FE-02.

TaskDragItem передаёт Codable карточку, версию pipeline и generation через
собственный UTType. Drop открывает подтверждение; stale, другой проект,
неизвестная версия, gate/terminal и запрещённый forward move не отправляют команд.
Причина отказа появляется спокойной строкой на доске. DropRules задаёт
предварительную доступность, окончательную проверку выполняет daemon.
Меню доступно и при legacy pipeline без versionHash; маршрут sheet фиксирует
полный доступный PipelineSummary. Компактные карточки имеют то же меню.

Cmd-Shift-P — пауза/продолжение, Cmd-Shift-M — перенос, Cmd-Shift-R — повтор,
Cmd-Shift-Delete — отмена. Меню валидируется по актуальному store, выбор стадии
поддерживает ↑/↓, Return подтверждает, Escape закрывает без отправки.
Операция блокирует повтор только для своей задачи. Mac/project pause имеет
свой scope и authoritative scheduler flags; текущие runs продолжаются.
Исправлено подтверждение project pause: daemon публикует settingsChanged с
полным набором flags, а не projectUpdated. Неизвестный набор не считается доказательством.

Cancel везде имеет keepBranch=false по умолчанию. Sheet объясняет точное
место `refs/kaban/archive/<task-id>`, сохранение только последнего коммита и
последующую очистку клона. Это namespace архитектуры §4, не отдельная refs/heads ветка.
При проверке настоящего клона найден дефект archiveTip: origin не содержит
коммиты, сделанные после local clone. Теперь импортируется точный tip без
записи FETCH_HEAD, tags, пользовательских refs, index или worktree; затем
публикуется archive ref. Path guards, outbox и подтверждение внешнего effect сохранены.

Retry отправляет optional grantAttempts: nil, 0 и положительное число различаются.
Отрицательный/нечисловой ввод не отправляется. Лимит показывается только если
он получен от источника. Предупреждение о принятии текущего suspicious set всегда
видимо отдельно от прокрутки; специализированные действия файлов остаются FE-18.
Mock использует те же команды/события, сохраняет paused Human Review и
не меняет посторонние карточки; counters/model при переносе следуют target summary.

## Проверки

- `KABAN_SCENARIOS=Scenarios/M1 swift test` на интегрированной базе `788b641`:
  577 тестов, 0 failures: Transport 29, Protocol 66, Kit 180, DaemonCore 176, BoardCore 126.
- Core tests проверяют typed drag/roundtrip, card/pipeline/generation stale,
  cross-project, неизвестный маршрут/версию, explicit cancel/grant, capability
  states, полный набор project flags и idempotent mock. Старые DTO fixtures проходят.
- Реальный git clone: keepBranch true сохраняет новый commit и его файл в
  archive ref перед удалением; false удаляет клон без archive. HEAD/main,
  пользовательские refs, status и FETCH_HEAD origin сохранены; чужой path отклонён.
- ProcessControlTests запускают две настоящие process groups с дочерними
  процессами: Mac/project pause оставляют обе живыми, pauseTask останавливает
  только выбранную. Wire tests сохраняют admission paused Human Review,
  supersede старый launch/cancel effect и не позволяют late result оживить задачу.
- Unsigned xcodebuild настоящего Kaban.app на `2b499d2` успешен.
- Native [keyboard smoke](screenshots/fe-07/keyboard.json) и
  [control smoke с системным фокусом](screenshots/fe-07/focus.json) проходят.
  Проверены настоящее меню, Return/Escape, ↑/↓, default keepBranch, review pause/resume,
  флаги и отсутствие отправки stale/cross-project drop.
- Отдельный [routing smoke](screenshots/fe-07/routing.json) явно не требует
  системной активации; не подменяет строгий control smoke. Первые локальные
  focus-запуски не получали key window; финальная строгая проверка успешна.
- [Native private daemon](screenshots/fe-07/live.json): настоящее WindowGroup,
  bundled stdio, новая SQLite DB и отдельный git repo; Mac/project pause,
  shared sheet Return для pause/resume/cancel. Три точные команды имеют
  подтверждение: pause/resume — correlated events, cancel — исходный receipt,
  покрытый authoritative snapshot. Повторов нет; scheduler paused, Cursor не запускался.
- Live QA принимает только два предусмотренных FE-02 доказательства: correlated
  event либо исходный matching receipt с positive seq, покрытый применённым snapshot.
  При ранней синхронизации первоначальный event-only QA дал отказ; диагностика
  исправлена без ослабления production state/pending правил.
- Context checker и `git diff --check` выполнены перед PR; exact-head CI проверяется отдельно.

## Оставшиеся границы

Ручные физические клавиши, pointer drag/drop, нажатие checkbox и полный
Tab/VoiceOver обход не проверены. Native smoke создаёт NSEvent и направляет
его настоящему menu/sheet; grant/keep кадры включают fixture state программно.
Два capture-запуска с bare boolean QA flag не создали WindowGroup;
повтор с явным `--qa-control-long YES` прошёл. Неполные кадры не используются.

Installed signed helper/XPC/reboot и живые Cursor/gates не проверялись.
Process/git/backend tests и private stdio не заменяют их системную приёмку.
Пять критериев FE-07 отмечены в границах перечисленных доказательств;
полный M1/MVP и специализированные FE-08–22 остаются открыты.
Недостающие designer states записаны в [отдельном файле](frontend-design-gaps.md).
