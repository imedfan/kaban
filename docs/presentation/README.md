# Презентация Kaban

Полный исходный [HTML из Drive](../archive/drive-2026-10-05/presentation/kaban-presentation.html)
и [оригинальная инструкция](../archive/drive-2026-10-05/presentation/README.md)
сохранены в Git. HTML содержит 31 слайд, стили, скрипты и встроенные макеты;
для просмотра внешние ресурсы не нужны.

Презентация утверждалась 4 октября, но основана на более ранних версиях:
архитектура v0.9, спецификация v0.6, frontend v0.4.1 и базовые PNG v0.1.
Часть предложений уже разрешена последующими решениями. Это материал презентации,
а текущие контракты — [архитектура](../architecture-v0.md),
[спецификация](../kaban-mvp-features-usecases.md), [журнал решений](../decisions-log.md).
Скрипт build.py и src/ не были опубликованы в этой папке Drive; пересборка из
старого README не воспроизводится. Сохранён полный готовый документ.
