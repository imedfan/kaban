# B2 — результаты fuzz/property-тестов

Дата: 2026-10-04. База: `origin/main` (`1d647ea`). Production-код,
существующие тесты, Package.swift, CI и Scenarios не изменены.
Новые файлы: `Team2MiniYAMLFuzzTests.swift`, `Team2ValidatorFuzzTests.swift`.

## Корпус и свойства

На каждый полный запуск:

| Корпус | Входы | Сиды |
|---|---:|---|
| Произвольный MiniYAML | 5 000 | `0xB2_2026_1004`, `0xCAFE_5000` |
| Почти корректные pipeline | 5 000 | `0xB2_2026_1004`, `0xFA11_5000` |
| Произвольные корни валидатора | 5 000 | `0xB2_A11_5000` |
| Сохранение quoted Unicode-скаляров | 128 | `0xB2_51CA1A` |

Генератор — фиксированный LCG с wrapping UInt64, без Swift `Hasher`,
системного RNG, часов и внешних зависимостей. Каждое fuzz-значение парсится
или валидируется дважды; сравнивается весь результат, включая порядок
диагностик, параметры, конфиг и номера строк. Первые два корпуса также
сверяют повторную генерацию при том же сиде.

Категории: случайные токены, block/flow, дубли ключей, табы, anchors/aliases,
незакрытые кавычки/коллекции, обрезанные строки, literal/folded scalars,
CRLF, кириллица/é/эмодзи/NUL, длинные строки. Pipeline-мутаторы дополнительно
покрывают диапазоны WIP, Auto, неверные типы/kind, циклы on_success,
unknown keys и активные задачи удалённой стадии.

Случайная вложенность ограничена 24 уровнями, случайные токены — 95
символами, pipeline — размером базового fixture плюс ограниченная мутация.
Отдельные случаи: 64 уровня block/flow, скаляр 65 536 символов, неверный
Unicode surrogate escape, обрезанная глубокая flow-коллекция.

MiniYAML: нет crash/hang на данном корпусе; ошибка с положительной строкой,
непустым сообщением и строкой в пределах CRLF-нормализованного текста.
Есть независимое свойство сохранения quoted Unicode и символов комментария.
Валидатор: nonthrowing API завершает все входы; результат детерминирован;
code непустой, path непустой с узкими исключениями ниже; невалидный результат
содержит хотя бы одну error. Пороговые assertions гарантируют смесь успешных
и ошибочных входов, а также семь существенных классов ValidationCode.
Конечный корпус не доказывает отсутствие зависания для любого YAML.

## Исключения и минимальное воспроизведение

Спека v0.8.24 §4.1 прямо задаёт пустой path для `yaml_syntax`, поэтому
буквальное требование B2 «всегда непустой path» для этого кода не применяется.
Положительный `params.line` проверяется; отдельный тест закрепляет исключение.

Для входов `x`, `[]` и пустой строки динамически получен единственный issue:
`code=type_mismatch`, `path=""`, `severity=error`,
`message="pipeline.yaml must be a mapping at the top level (line 1)"`.
Источник: `Sources/KabanKit/Pipeline/PipelineParser.swift:29`.
Это отдельный вопрос root-path контракта, не установленный security-дефект:
[issue #12](https://github.com/imedfan/kaban/issues/12).

Основной arbitrary-root fuzz активен: исключение распознаётся только для
успешно разобранного немаппингового корня с одним `type_mismatch`; mapping
диагностики продолжают строго проверять path. Только отдельный strict-path
тест условно XCTSkip, пока воспроизводится известная пустая root-диагностика;
при исправлении он автоматически проверит новое поведение.
Падений/зависаний/исключений production-кода не найдено, crash-фикстур нет.
Первый локальный запуск выявил ошибку самого тестового подсчёта CRLF-строк;
подсчёт исправлен, production-код не менялся.

## Проверки и ограничения

Среда: Darwin arm64, Apple Swift 6.4 (`swiftlang-6.4.0.34.1`), target
`arm64-apple-macosx27.0.0`. Полный прогон выполнен с
`KABAN_SCENARIOS=Scenarios/M1 swift test`, project-temp Swift caches и
`--disable-sandbox`; внешняя Codex sandbox снята для существующих real-git
тестов (в ней platform temp-dir warnings создают ложные ошибки).
Все временные кеши и вывод остались в `/private/tmp`.

Финальные результаты полного прогона указаны ниже. Linux-прогон здесь
не выполнялся: доступной Linux-среды нет, Docker/системные зависимости не
устанавливались. Требование полного Linux-прогона <60 секунд остаётся
проверкой CI; время этого Mac не выдаётся за Linux-результат.

- Полный прогон: 193 теста (32 protocol + 115 kit + 46 board), 0 failures,
  1 условный skip (#12). Все прежние 185 тестов проходят без новых skip.
- KabanKit: 22,462 с; Protocol: 0,060 с; BoardCore: 0,072 с.
  Сумма времени тестовых модулей — 22,594 с; incremental build — 0,96 с.
- Новые активные тесты: 7, около 2,69 с суммарно в финальном полном прогоне.

Fuzz-only: `swift test --filter Team2`. Fixed seeds и индекс входят в assertion
