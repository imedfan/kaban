## Что означает покрытие

Учтены UC-01…25 и каждый нормативный абзац/элемент/строка таблицы §1/§4,
включая §4.1 (37 кодов, placeholders, severity/fallback и labels).
Строки таблицы ниже сокращают длинное требование, точный пункт определяет S+L.
Связанный критерий AC не означает, что он проверяет каждую деталь новой спеки.
Отсутствующий точный критерий и отсутствующий сценарий помечены явно.

Локальный baseline: 185 тестов, 0 failures, полный прогон с
`KABAN_SCENARIOS=Scenarios/M1`. Kit сообщает 20 full и 13 partial; `full`
относится к его pure-state subset: почти везде `event taskUpdated` unchecked.
BoardCore проверяет projection events другим тестом, не daemon transaction,
журнал/GRDB, scheduler fairness или реальные процессы. `uc` tags — обратные
ссылки, а не доказательство семантического покрытия. Например restart JSON
не содержит UC-12 tag, но относится к нему по `daemon_restart`.
Все 33 файла декодируются; это не принятие M1 end-to-end.

## Приоритетные пробелы

1. **Высокий M1: admission/WIP/fairness/flags** (UC-03/06/09/14, §1.1/1.2).
   Сценарии есть, но multi-task tick не выполняется: `KabanDaemonCore` отсутствует.
   Ошибка этого слоя запускает слишком много run или блокирует чужие задачи.
2. **Высокий M1: read-only/default return/ручные команды** (UC-05/07, §1.3).
   Нет dedicated JSON для requestChanges/reject read-only, cancel и nil target.
   Неправильный возврат обходит роль стадии либо зависает без цели; AN3 drafts.
3. **Высокий M1: recovery/ordering/idempotency** (UC-12/13, инвариант AC journal).
   No-charge reason проверен, но restart replay/catch-up и atomic commit/next-run
   semantics не подтверждены. Возможны потерянные команды и расхождение UI.

Следующие M1 gaps: UC-02 create/edit/acceptance, UC-19 effective policy JSON,
§1.4 physical WIP refs/clone recovery, все новые точные code/params критерии.
Существующие unit tests частично проверяют validator, policy и identity;
отсутствие M1 JSON **не** означает отсутствие любого unit test.
M2–M4: MCP, Seatbelt, real clone/git, merge и live quota отмечены отдельно.
M3: renderer/text/accessibility не существует; дизайнерские работы исключены.
Issues #9/#10/#11 — уже заведённые spec decisions, не новые runtime ошибки.
