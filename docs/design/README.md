# Документация дизайна Kaban

Полные документы дизайнера из Drive находятся здесь. Локальные изображения и
ссылки исправлены; оригинальные байты доступны по реестру импорта.
Токены, исходники и PNG находятся в [design/](../../design/README.md).

| Документ | Использование | Исходники/PNG |
|---|---|---|
| [Base v0.1](base.md) | Базовая композиция, токены, incident, общие настройки | [base](../../design/) |
| [v0.2](v0.2.md) | WIP, флаги, модели, квота, MCP | [v0.2](../../design/v0.2/) |
| [v0.2.1](v0.2.1.md) | Suspicious files, git-политика, возвраты, автор проекта | [v0.2.1](../../design/v0.2.1/) |
| [Бренд](brand.md) | Иконка, словесный знак, Onest и лицензия | [brand](../../design/brand/) |
| [Маскоты и фактуры](mascots.md) | Набор, стабильные индексы, seed, коллизии, состояния | [mascots](../../design/mascots/) |

Новая версия дополняет предыдущую: v0.2.1 для затронутых компонентов,
v0.2 для моделей/квоты/флагов, base для оставшихся. Описания и вопросы в этих
документах относятся к указанному срезу; их разрешают последующие
[решения](../decisions-log.md) и [frontend-требования](../frontend-plan-v0.md).
Статусы и команды определяет Protocol/архитектура. Рендер fixtures не является
автоматом приложения. Приложение реализуется нативным SwiftUI и проверяется
в настоящем окне по [приёмке](../frontend/acceptance.md).
