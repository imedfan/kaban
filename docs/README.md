# Документы Kaban

Git — основное место ведения документации. Актуальные документы из папки
[kaban на Drive](https://drive.google.com/drive/folders/1UEqVURZaSrLOXVW_0Mr7ArvIGytfxBjR)
сверены и перенесены 5 октября 2026. Для обычной разработки подключение к Drive не нужно.

Текущее поручение пользователя приоритетнее документов. Решения уточняют
архитектуру и спецификацию; текущее состояние описывает реализацию и не меняет
требования под код. Для одной задачи читай относящиеся к ней разделы.

## Что перенесено из Drive

[Реестр импорта](drive-import-2026-10-05.json) содержит 18 документов: file ID,
URL, дату изменения, размер, SHA-256 оригинала, локальный источник и рабочий путь.
Шесть основных документов и три development-файла сверены с Git. Архитектура
в Git v0.11.24 новее Drive v0.11.23; frontend v0.5.37 новее v0.5.36;
backend v0.2 новее v0.1. Спецификация и приёмка совпадают с базой Git.
Более свежие Git-решения сохранены. Добавлены недостающее исследование,
пять полных документов дизайнера и презентация. Отменённый чек-лист team2
сохранён в архиве. Старые одноимённые версии и backup-архивы Drive не являются рабочими требованиями.

Изменения дальше вносятся в рабочие файлы через Git. Drive остаётся внешним
историческим источником; опубликованные ранее копии не управляют разработкой.
Исходные файлы Drive при переносе не изменялись.

Проверка навигации и закреплённых исходников: `python3 tools/check-project-context.py`.
