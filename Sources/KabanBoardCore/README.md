# KabanBoardCore

Состояние доски в приложении. Модуль зависит **только от `KabanProtocol`** (арх. §2 и §5), без SwiftUI и AppKit, и собирается на Linux.

Карточку целиком заменяют `taskCreated`, `taskUpdated` и `taskEdited`. `taskTransitioned` даёт только подсказку для анимации. Остальные журнальные события попадают в ленту и не меняют карточку. Неизвестный `type` пропускается.

Догонка помнит последний применённый `seq` у каждой подписки: `seq <= last` отбрасывается, `seq > last + 1` поднимает resync. `resyncRequired` не переписывает карточки — новое состояние приходит через `replace(with:)`. Эфемерные события без `seq` пишут только эфемерное состояние.

`PendingCommands` помечает карточку «отправлено» по `commandId` и снимает метку по `taskUpdated` с тем же `commandId` или по ошибке ответа.

`BoardSet` хранит порядок дорожек отдельно от порядка добавления. `BoardSetStore` пишет его в переданное key-value хранилище (настройки приложения, не демон). Старый JSON-массив id читается как порядок дорожек и как порядок добавления. `DropRules` отвечает, можно ли бросить карточку в столбец, и не выполняет команду. Вперёд из Backlog в соседнюю стадию можно только при `TaskCard.hasAcceptanceCriteria`. Стадия с непустым `StageSummary.gates` между источником и целью закрывает перенос так же, как столбец `gate`.

Бейдж инцидентов проекта — `ProjectSummary.openIncidentCount`. Агрегаты берутся только из снимка и `projectAdded`/`projectUpdated`/`projectRemoved`; глобальный счётчик — сумма сводок проектов проекции. `incidentOpened`/`incidentResolved` меняют только детали и ленту. Демон присылает `projectUpdated` в той же транзакции: после всей транзакции порядок событий не влияет на сумму; промежуточный кадр до сводки может показывать предыдущее значение. `stageLoad` приходит в снимке и обновляется `stageLoadChanged`; модуль слоты не пересчитывает.

`IdentityDraft` держит введённые имя и почту после отказа `identity_required`. Первый отказ без `identity` подставляет найденные `CommandError.params` и не подсвечивает поля; отказ вызову с `identity` подсвечивает только `missing` / `invalid` и не затирает введённое. `CommandErrorText` подставляет `{ключ}` из `params` и при нехватке ключа оставляет `message`.

`MascotKit` по строке `mascotSeed` выбирает эмодзи и фактуру края. `resolveBoard` обходит проекты в порядке добавления на доску. Поле `ProjectSummary.mascotSeed` на этом протоколе уже есть, кит принимает саму строку.
